How to open ZXP Manager

ZXP Manager is free and open source, but it isn't signed with a paid Apple or Microsoft certificate yet. So the first time you open it, your computer asks you to confirm that you trust it. You only need to do this once.

  1. Install the app

    Open the .dmg file and drag ZXP Manager onto the Applications folder.

  2. Open ZXP Manager

    Open it from Applications. macOS says “ZXP Manager” Not Opened. Click Done.

  3. Allow it in System Settings

    Open System Settings → Privacy & Security, scroll down to the Security section and click Open Anyway next to the message about ZXP Manager.

  4. Confirm

    Click Open Anyway again and enter your password (or use Touch ID). That's it: from now on ZXP Manager opens normally.

Don't see the Open Anyway button? It appears for about an hour after you try to open the app. Open ZXP Manager once more, then go back to Privacy & Security.

Prefer the Terminal?

After copying the app to Applications, this command does the same in one step:

xattr -dr com.apple.quarantine "/Applications/ZXP Manager.app"

Choose a version

Installer

Adds ZXP Manager to the Start menu and opens .zxp files with a double-click. Uninstall it from Settings → Apps.

Portable

Nothing to install: unzip it and keep ZXPManager.exe in any folder you like.

Open it

  1. Start ZXP Manager

    Open the installer, or ZXPManager.exe from the unzipped portable version.

  2. If a blue window appears

    Windows may say Windows protected your PC. Click More info.

  3. Run it

    Click Run anyway. Windows only asks once.

On a few computers Smart App Control is turned on: it blocks apps that aren't signed and doesn't offer a Run anyway button. In that case ZXP Manager can't be opened for now.

You'll also need the Adobe Creative Cloud desktop app, installed and signed in. ZXP Manager uses Adobe's own plugin installer, which comes with it.

Why trust it? The source code is public: github.com/oddmoth/zxp-manager. Something not working? Let us know.
